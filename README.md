# Submission Analisis E-Commerce

Proyek ini menganalisis data Brazilian E-Commerce Public Dataset by Olist.

## Struktur

- `dashboard/dashboard.py`: dashboard Streamlit.
- `data/`: seluruh dataset yang digunakan.
- `Proyek_Analisis_E_Commerce.ipynb`: notebook analisis.
- `requirements.txt`: daftar library Python.
- `url.txt`: URL deployment dashboard.

## Menjalankan Dashboard

1. Buat virtual environment dan instal dependensi:

   ```bash
   pip install -r requirements.txt
   ```

2. Jalankan dashboard:

   ```bash
   streamlit run dashboard/dashboard.py
   ```
